# ATLAS

**Autonomous Multi-Agent Document Intelligence Platform**

> 🚧 **Work in progress.** This repository is under active development.
> Features are listed below only once they are implemented.

## Goal

ATLAS lets you upload professional documents (PDF, DOCX, PPTX, images) and
interact with their content through a team of AI agents, with answers
grounded in the documents and verifiable citations (document and page).

It is designed to run fully locally with [Ollama](https://ollama.com), with
an optional external LLM provider for the online demo.
